# Minutide name screen

Checked 2026-11-11. This records a candidate-name screen, not a legal clearance, adopted product name, domain purchase, or publication record.

Subsequent decision: after reviewing this screen, the user chose Minutide and authorized source publication under Elaren. See `DECISIONS.md`. The observations below describe the state at the time of the screen; they are not current reservation or publication evidence.

## Assessment

Minutide remains a promising candidate for the independent time-tracking app. No exact-name app or public GitHub project was identified in the checks below. Similar commercial names exist, particularly **Minitide** and **miniTide**. Their existence should remain visible in any later clearance review.

The user likes Minutide and requested a more thorough check. The implemented display name and identifiers still use Stiint Community; no product rename has been applied by this research pass.

## Similar names and other occurrences

- **Minitide**: [itide's Norwegian logistics portal](https://itide.no/minitide/) supports ordering, shipment tracking, invoices, reporting, and user administration. This is an actual software use, spelled one letter differently from Minutide.
- **miniTide**: Valeport's [official miniSERIES manual](https://www.valeport.co.uk/content/uploads/2021/08/miniSERIES-Operating-Manual.pdf), introduction, identifies an underwater tide gauge/level recorder that works with DataLog software. This is an actual product name, also one letter different.
- **MinTid**: [EG A/S's iPhone/iPad productivity app](https://apps.apple.com/us/app/mintid/id1253923606) displays workplace shift plans and requires an employer using Tjenestetid. Its spelling is less close, but it occupies a related scheduling/productivity context.
- **Minutide** appears literally in [NameStation's generated movie-website name list](https://www.namestation.com/names/movie-website), under invented names. This proves the word has appeared before; the listing itself does not establish an operating product or ownership.
- General exact-name web searches, social-domain searches, and indexed package/product directory searches did not identify an operating brand called Minutide. Many results were ordinary Estonian text or unrelated transcription/recognition errors. No social handle was individually verified or reserved.

## Trademark evidence and limits

An independent worker searched the live [USPTO trademark database](https://tmsearch.uspto.gov/search/) using field-tag mode. Final lowercase queries, without a class filter:

| Query | Observed result |
| --- | --- |
| `CM:minutide` | No results found |
| `CM:minitide` | No results found |
| `CM:apple` (positive control) | 5,100 results |

The control confirms the interface could return results. Earlier uppercase searches were not used as decisive evidence because the official [field-tag guide](https://www.uspto.gov/sites/default/files/documents/TM-FederalTrademarkSearching-FieldTags-handout.pdf) requires lowercase search terms.

Additional worker-reported queries returned no results: `CM:"mini tide" AND IC:(009 042)`, `CM:"minute tide" AND IC:(009 042)`, `CM:minutime AND IC:(009 042)`, and `CM:minutiae AND IC:(009 042)`. These are bounded searches of the named variants and classes, not an exhaustive phonetic search.

The broader `CM:/.*minut.*/ AND IC:(009 042)` returned 1,001 results that were not fully reviewed. Basic Wordmark-mode `MINI TIDE` returned thousands of token matches and was not treated as an exact-phrase result. No completed WIPO or comprehensive foreign/state trademark search is claimed. No application or reservation was submitted.

Trademark risk depends on similar names and related goods/services, not merely an identical-word match. See the USPTO's [comprehensive clearance guidance](https://www.uspto.gov/trademarks/search/comprehensive-clearance-search-similar-trademarks) and [likelihood-of-confusion guidance](https://www.uspto.gov/trademarks/search/likelihood-confusion). State, foreign, unregistered/common-law, and unpublished uses are not comprehensively cleared by this screen.

## Branding judgment

The intended reading is “MIN-uh-tide,” suggesting minutes and the flow of time. Some people may hear or type Minitide or Minute Tide. Consistent spelling and a descriptive app title such as **Minutide: Time Tracker** would help explain the product. This is a branding judgment, not evidence of legal availability.

Public name adoption, identifier changes, a GitHub destination, App Store Connect title availability, and any domain purchase remain separate future actions.
